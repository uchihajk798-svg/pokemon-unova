Ajuda rápida

Como conseguir o patch?

Abra o repositório, entre em Actions e escolha a última execução aprovada. Baixe pokemon-unova-bps na seção Artifacts e extraia o arquivo pokemon-unova.bps.

Para construir a ROM base com o código-fonte, siga as instruções do README. Esta página é um utilitário; não significa que a campanha já tenha sido testada integralmente.
